Overview

This report summarizes the BSC-GHR legacy dengue model used for the 3rd IMDC 2026 forecasting challenge. It brings the validation and production rounds into one report, with observed cases where available, predictive medians, and posterior predictive uncertainty intervals.

NoteCountry-wide aggregation

The country-wide series is the sum of the 26 federative units included in the submitted model. Espírito Santo (UF 32) is not included, so the country-wide figures should be interpreted as the aggregate of the modelled units rather than a complete Brazil total.

The production forecast covers 52 weeks, from 11 October 2026 to 03 October 2027, with 1000 posterior predictive draws per state-week. The submitted model is tied to Git commit b3af423fbf2f714612e6b8d4061daafa5bfda83c.

Model and aggregation notes

The submitted model is a negative-binomial R-INLA model fitted at the health-region × epidemiological-week level with population as the exposure. The legacy specification includes a BYM2 spatial effect for health region, a state-specific cyclic RW2 seasonal effect, an iid year effect, climate covariates, and the selected climate interactions.

Forecasts are generated from posterior predictive draws at health-region level and aggregated draw-by-draw to states. For both the validation rounds and the production forecast, country-wide and forecast-horizon summaries in this report are constructed by summing corresponding draws before calculating medians and uncertainty intervals. This preserves the dependence represented by each joint posterior predictive draw.

# ---- Helpers -------------------------------------------------------------

sum_observed <- function(x) {
  if (all(is.na(x))) NA_real_ else sum(x, na.rm = TRUE)
}

sum_draws <- function(x) {
  if (length(x) == 0L) {
    stop("Cannot aggregate an empty set of posterior predictive draws.")
  }
  Reduce(`+`, x)
}

add_intervals <- function(data) {
  data |>
    dplyr::mutate(
      pred = purrr::map_dbl(.pred_samples, ~ stats::median(.x, na.rm = TRUE)),
      lower_50 = purrr::map_dbl(.pred_samples, ~ stats::quantile(.x, 0.25,  na.rm = TRUE, names = FALSE)),
      upper_50 = purrr::map_dbl(.pred_samples, ~ stats::quantile(.x, 0.75,  na.rm = TRUE, names = FALSE)),
      lower_80 = purrr::map_dbl(.pred_samples, ~ stats::quantile(.x, 0.10,  na.rm = TRUE, names = FALSE)),
      upper_80 = purrr::map_dbl(.pred_samples, ~ stats::quantile(.x, 0.90,  na.rm = TRUE, names = FALSE)),
      lower_90 = purrr::map_dbl(.pred_samples, ~ stats::quantile(.x, 0.05,  na.rm = TRUE, names = FALSE)),
      upper_90 = purrr::map_dbl(.pred_samples, ~ stats::quantile(.x, 0.95,  na.rm = TRUE, names = FALSE)),
      lower_95 = purrr::map_dbl(.pred_samples, ~ stats::quantile(.x, 0.025, na.rm = TRUE, names = FALSE)),
      upper_95 = purrr::map_dbl(.pred_samples, ~ stats::quantile(.x, 0.975, na.rm = TRUE, names = FALSE))
    )
}

aggregate_predictions <- function(data, group_vars, include_observed = TRUE) {
  if (!".pred_samples" %in% names(data)) {
    stop("`.pred_samples` is required for draw-by-draw aggregation.")
  }

  has_observed <- include_observed && "cases" %in% names(data)

  out <- data |>
    dplyr::group_by(dplyr::across(dplyr::all_of(group_vars))) |>
    dplyr::summarise(
      .pred_samples = list(sum_draws(.pred_samples)),
      cases = if (has_observed) sum_observed(cases) else NA_real_,
      .groups = "drop"
    )

  add_intervals(out)
}

validation_metrics <- function(data, level) {
  data |>
    dplyr::group_by(.split_id) |>
    dplyr::summarise(
      level = level,
      n = dplyr::n(),
      mae = mean(abs(pred - cases), na.rm = TRUE),
      rmse = sqrt(mean((pred - cases)^2, na.rm = TRUE)),
      coverage_50 = mean(cases >= lower_50 & cases <= upper_50, na.rm = TRUE),
      coverage_80 = mean(cases >= lower_80 & cases <= upper_80, na.rm = TRUE),
      coverage_90 = mean(cases >= lower_90 & cases <= upper_90, na.rm = TRUE),
      coverage_95 = mean(cases >= lower_95 & cases <= upper_95, na.rm = TRUE),
      .groups = "drop"
    ) |>
    dplyr::relocate(level, .after = .split_id)
}

plot_forecast <- function(data, observed = FALSE, title = NULL, subtitle = NULL) {
  p <- ggplot(data, aes(x = date)) +
    geom_ribbon(
      aes(ymin = lower_95, ymax = upper_95),
      fill = "#3B82F6", alpha = 0.12
    ) +
    geom_ribbon(
      aes(ymin = lower_80, ymax = upper_80),
      fill = "#3B82F6", alpha = 0.18
    ) +
    geom_ribbon(
      aes(ymin = lower_50, ymax = upper_50),
      fill = "#3B82F6", alpha = 0.28
    ) +
    geom_line(aes(y = pred), colour = "#1D4ED8", linewidth = 0.65)

  if (observed) {
    p <- p + geom_line(aes(y = cases), colour = "black", linewidth = 0.55)
  }

  p +
    scale_y_continuous(
      labels = scales::label_comma(),
      expand = expansion(mult = c(0.01, 0.08))
    ) +
    scale_x_date(date_labels = "%Y-%m", date_breaks = "3 months") +
    labs(
      title = title,
      subtitle = subtitle,
      x = NULL,
      y = "Weekly dengue cases",
      caption = if (observed) {
        "Blue: predictive median; black: observed cases. Shading: 50%, 80%, and 95% posterior predictive intervals."
      } else {
        "Blue: predictive median. Shading: 50%, 80%, and 95% posterior predictive intervals."
      }
    ) +
    theme_minimal(base_size = 11) +
    theme(
      plot.title.position = "plot",
      panel.grid.minor = element_blank(),
      axis.text.x = element_text(angle = 45, hjust = 1),
      plot.caption = element_text(hjust = 0)
    )
}

plot_states <- function(data, observed = FALSE, title = NULL) {

    theme(
      axis.text.x = element_text(angle = 45, hjust = 1, size = 6.5),
      axis.text.y = element_text(size = 6.5),
      strip.text = element_text(size = 8),
      plot.caption = element_text(size = 8)
    )

  if (requireNamespace("geofacet", quietly = TRUE)) {
    p + geofacet::facet_geo(
      ~ uf,
      grid = br_states_grid,
      label = "name",
      scales = "free_y"
    )
  } else {
    p + facet_wrap(~ uf, scales = "free_y", ncol = 5)
  }
}

# Overview

This report summarizes the **BSC-GHR legacy dengue model** used for the 3rd IMDC 2026 forecasting challenge. It brings the validation and production rounds into one report, with observed cases where available, predictive medians, and posterior predictive uncertainty intervals.

::: {.callout-note}
## Country-wide aggregation

The country-wide series is the sum of the **26 federative units included in the submitted model**. Espírito Santo (UF 32) is not included, so the country-wide figures should be interpreted as the aggregate of the modelled units rather than a complete Brazil total.
:::

The production forecast covers **`r nrow(production_country)` weeks**, from **`r format(min(production_country$date), "%d %B %Y")`** to **`r format(max(production_country$date), "%d %B %Y")`**, with **`r length(production_state$.pred_samples[[1]])` posterior predictive draws** per state-week. The submitted model is tied to Git commit `r model_commit`.

# Model and aggregation notes

The submitted model is a negative-binomial R-INLA model fitted at the **health-region × epidemiological-week** level with population as the exposure. The legacy specification includes a BYM2 spatial effect for health region, a state-specific cyclic RW2 seasonal effect, an iid year effect, climate covariates, and the selected climate interactions.

Forecasts are generated from posterior predictive draws at health-region level and aggregated **draw-by-draw** to states. For both the **validation rounds** and the **production forecast**, country-wide and forecast-horizon summaries in this report are constructed by summing corresponding draws before calculating medians and uncertainty intervals. This preserves the dependence represented by each joint posterior predictive draw.
